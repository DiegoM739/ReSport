
# ReSport — E-commerce de Productos Deportivos
### Autor: Diego Medina 
### Fecha: 23 de mayo de 2026

##  Resumen

**ReSport** es un sistema de gestión de e-commerce orientado a la comercialización de productos deportivos (bandas elásticas, foam rollers, pesas, suplementación), dirigido a **deportistas** y **personas en proceso de recuperación**.

El proyecto se desarrolla aplicando los cuatro principios de la **Programación Orientada a Objetos** —herencia, polimorfismo, encapsulación y abstracción— utilizando **Go**, base de datos relacional y despliegue en `localhost`.

##  Objetivos

### Objetivo general
Desarrollar un sistema de gestión de e-commerce que permita administrar de forma integral el catálogo deportivo de ReSport y el proceso de compra de clientes, aplicando los principios de la Programación Orientada a Objetos.

### Objetivos específicos
- Diseñar el modelo de clases del sistema mediante herencia, polimorfismo y encapsulación.
- Implementar el módulo de gestión de productos con operaciones **CRUD**.
- Desarrollar el módulo de clientes con registro, autenticación y gestión de perfil.
- Construir el flujo de compra mediante carrito, generación de pedido y pago simulado.
- Implementar un panel administrativo para la gestión de catálogo y pedidos.
- Conectar el sistema a una base de datos relacional para persistencia de datos.
- Documentar el código y versionarlo en **Git / GitHub**, con despliegue en `localhost`.
